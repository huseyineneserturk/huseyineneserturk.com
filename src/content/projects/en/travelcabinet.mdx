**TravelCabinet** is a sales-automation system built to help travel agencies run
their daily operations. It brings hotel reservations, flight tickets and tour
sales together in one interface.

- Hotel, flight and tour sales management
- A C# / .NET desktop solution
- SQL Server data layer
